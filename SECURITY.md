# Security Policy

## Scope

This repository is for a defensive and educational desktop simulator.
It does not contain real malware, exploitation logic, persistence code,
credential theft, or offensive automation.

## Reporting a vulnerability

If you find a security issue in the application itself, open a private report
with:

- steps to reproduce
- affected platform
- expected behavior
- actual behavior

Do not submit real malware samples, live credentials, or active payloads in
issues or pull requests.

## Out-of-scope submissions

The following are out of scope for this project:

- requests to add offensive features
- exploit development
- persistence on the host machine
- real command execution chains
- live network beaconing or data exfiltration

## Safe contribution rules

Contributions must keep all suspicious behavior synthetic and contained to
generated UI output only.
